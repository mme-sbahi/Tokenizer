What is a Wallet?

A wallet is an application used to interact with a blockchain.

Example:

MetaMask
Trust Wallet
Public Address

Example:

0x123456...

Used to:

Receive tokens
Identify accounts

Can be shared publicly.

Private Key

Used to:

Sign transactions
Prove ownership

Must remain secret.

Anyone with the private key controls the wallet.

Seed Phrase

A set of recovery words generated during wallet creation.

Used to restore wallet access.

Should never be shared.
