What is a Blockchain?

A blockchain is a distributed ledger that stores transactions in blocks linked together using cryptographic hashes.

Each block contains:

Transactions
Timestamp
Previous block hash
Its own hash

Because each block references the previous one, modifying historical data would require modifying all subsequent blocks, making the blockchain resistant to tampering.

Why use Blockchain?

Traditional systems rely on a central authority.

Example:

Bank
│
├── Stores balances
├── Validates transfers
└── Controls data

Blockchain removes the need for a central authority.

Instead:

Network Nodes
│
├── Store copies of data
├── Validate transactions
└── Reach consensus
Advantages
Decentralization
Transparency
Immutability
Security
